# seed データについて

`seed_items.json` は、デモ用の初期商品 300 件です。

## 出典とライセンス

- データセット: **MerRec**(Mercari US の行動ログ。Mercari, Inc. 公開)
  https://huggingface.co/datasets/mercari-us/merrec
- ライセンス: **CC BY-NC 4.0**(表示 - 非営利)
  https://creativecommons.org/licenses/by-nc/4.0/
- **非営利の利用に限ります。** このリポジトリではハッカソン(学習・デモ)目的でだけ使っています。商用のサービスにこのデータ・このデータで学習したモデルを使うことはできません。
- 使ったのは 2023 年 5 月分(`20230501/`)のうち 4 ファイル(`000000000000`〜`000000000003.parquet`)です。

## 作り方

```bash
.venv/bin/python -m ml.make_seed
```

- 価格モデルの **test 分割**(学習に使っていない商品)から選んでいます。
- 17 のトップカテゴリそれぞれに 10 件ずつ、残り 130 件はカテゴリの件数に比例して配分しています(乱数の種は 42 で固定)。
- 選ぶ条件: 価格 3〜2000 USD、タイトル 12〜70 文字で ASCII のみ、タイトルの重複なし、デモ画面に出したくない語(スクリプト内の一覧)を含まない。

## 各項目

| 項目 | 中身 |
|---|---|
| `title` | 元データの商品名(英語のまま・無加工) |
| `category` | 元データのトップカテゴリ名(`c0_name`) |
| `brand` | 元データのブランド名。無ければ `null` |
| `condition` | 元データの状態(`New` / `Like new` / `Good` / `Fair` / `Poor`) |
| `price_jpy` | 元の価格(USD)× 150 を 100 円単位に四捨五入した値。**固定レートでの換算で、日本の相場ではありません** |
| `description` | 上の項目から機械的に組み立てた 1 文(ブランド・商品名・カテゴリ・状態)。元データに説明文は無いので、それ以外の内容は書いていません。カテゴリと状態の日本語はこちらで付けた訳です |
| `source` | 元データの `item_id` と元の価格(USD) |

元データに商品の画像・説明文・出品者の情報は含まれていません。
